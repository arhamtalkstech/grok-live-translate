Access Manager frequently asked questions

What is Access Manager?
Access Manager is the self-service area in Vantorra Online where company administrators manage their own users, roles, and permissions without sending forms to the bank.

How do I add a new user?
Step 1. Log in to Vantorra Online and open Access Manager from the menu.
Step 2. Select Users, then Add user.
Step 3. Enter the person's name, email, and phone number.
Step 4. To save time, use Copy from existing user: pick a colleague with the same job, and their roles and permissions are copied to the new user.
Step 5. Select Submit. Changes need a second administrator to approve them (four-eyes principle).
Step 6. After approval, the new user receives an activation letter by email.

How do I change permissions for a user?
Open Access Manager, select Users, and pick the user. Choose Permissions. You can change account permissions for many accounts at once with Bulk edit: tick the accounts in one row and set View, Prepare, or Approve. Select Submit; a second administrator approves the change.

What roles exist?
Viewer can see balances and statements. Preparer can create payments. Approver can approve payments up to their limit. Administrator manages users in Access Manager.

Why does every change need a second administrator?
For security, every user or permission change in Access Manager is approved by a second administrator before it takes effect.

Can I reset another user's Vantorra Key?
Yes. Administrators can reset a user's Vantorra Key in Access Manager under Users, Security, Reset Vantorra Key. The user then receives a new activation letter.
